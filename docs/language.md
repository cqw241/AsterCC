# Aster 0.1 语言契约

## 文件和声明

UTF-8 源文件后缀 `.aster`。标识符为 ASCII 字母或下划线开头，后接字母、数字或下划线。支持 `//` 行注释和可嵌套的 `/* */` 块注释。

```text
module      = { import | record | enum | function } ;
import      = "import" identifier { "." identifier } ";" ;
record      = "struct" identifier "{" { identifier ":" type [ "," ] } "}" ;
enum        = "enum" identifier "{" { identifier [ "=" integer ] [ "," ] } "}" ;
function    = "fn" identifier "(" [ parameters ] ")" "->" type block ;
type        = "i64" | "u8" | "bool" | "str" | "void" | identifier | "[]" type ;
block       = "{" { statement } "}" ;
```

记录名称采用大写字母开头，以消除记录字面量和条件语句块之间的语法歧义。类型名在整个编译单元中唯一；函数按模块区分。`import std.io;` 加载根目录中的 `std/io.aster`，通过 `io::function()` 访问。未限定的函数名先查当前模块，再查已加载模块中唯一的同名函数；重名时须限定。支持函数前向引用和相互递归，模块作为一个完整程序编译，不提供独立链接的模块 ABI。

入口必须是 `fn main() -> i64`。参数不可重新赋值。只有局部 `var` 可重新赋值；没有模块全局变量。所有局部绑定必须初始化，`let` 不可重新赋值。

## 类型和数据

| 类型 | 语义 |
|---|---|
| `i64` | 64 位二进制补码有符号整数 |
| `u8` | 8 位无符号整数 |
| `bool` | 严格布尔类型；无整数到条件的隐式转换 |
| `str` | 不可变 UTF-8 字节串，可包含 NUL；`s[i]` 返回 `u8` |
| `[]T` | 类型化、可增长、共享引用的数组 |
| 结构体 | 按值复制；其中的数组或字符串字段仍保持各自的引用语义 |
| 枚举 | 具名的 64 位枚举类型；枚举成员通过 `Color::Red` 使用 |
| `void` | 无值返回类型，不可作为字段、元素或变量类型 |

整数支持十进制与 `0x`/`0X` 十六进制字面量，范围为一个 64 位位模式；不把前导零解释为八进制。负号是单独的运算符。普通整数字面量默认 `i64`；直接位于预期 `u8` 的初始化位置时可推断为 `u8`。复杂表达式不进行隐式整数宽度转换，使用 `as` 显式转换。

空数组需要上下文类型，例如 `let xs: []i64 = [];`。非空数组可以推断元素类型。结构体字面量必须恰好初始化所有字段，允许字段顺序不同，按源代码顺序求值。

```text
struct Pair { n: i64, data: []i64, }
let p: Pair = Pair { n: 1, data: [2], };
var q: Pair = p;
q.n = 9;             // p.n 仍为 1
push(q.data, 3);     // p.data 与 q.data 指向同一数组，长度都为 2
```

`let` 约束绑定和记录字段的重新赋值，不冻结其引用的数组。数组可以存放记录、布尔或其他数组；数组控制块固定，扩容只替换内部缓冲区。

## 表达式和控制流

支持函数调用、字段和索引访问、数组及记录字面量、`as` 转换、一元 `! - ~`，以及以下二元运算符，按优先级从低到高排列：

```text
||
&&
|
^
&
== !=
< <= > >=
<< >>
+ -
* / %
```

表达式从左向右求值。`&&`、`||` 短路；赋值目标中的索引只求值一次。语句包括声明、赋值、表达式、块、`if/else`、`while`、`break`、`continue`、`return`。声明具有词法作用域，可在内层块遮蔽外层名称，同一作用域不允许重复声明。

整数加减乘、取负及按位运算均按位宽回绕。移位量对位宽取模；`i64 >>` 为算术右移，`u8 >>` 为逻辑右移。除法向零截断；最小 `i64 / -1` 返回最小 `i64`，余数为零；除零终止。字符串只支持拼接和内容相等比较；数组与结构体不提供隐式相等比较。

`i64/u8/bool/枚举` 之间可显式转换：窄化保留低位，布尔转整数得到 0/1，整数转布尔判断是否非零。记录和数组不允许伪装为整数或相互强制转换。值结构体不能直接或间接无限包含自身；通过数组引用的递归合法。

## 内建与标准库

| 接口 | 类型或行为 |
|---|---|
| `len(value)` | 数组或字符串长度，返回 `i64` |
| `push(array, value)` / `pop(array)` | 原地修改数组，返回 `void` |
| `slice(str, start, length)` | 返回一个字节子串 |
| `itoa(i64)` / `parse_int(str)` / `chr(i64)` | 基础字节和整数转换 |
| `join([]str, separator)` | 一次分配的字节缓冲拼接原语 |
| `print/println/eprint(str)` | 标准输出、换行输出、标准错误 |
| `print_int/println_int(i64)` | 整数输出 |
| `read_file(str)` / `write_file(str,str)` | 文件内容读取或写入状态 |
| `args()` / `env(str)` | 命令行参数或环境值 |
| `run([]str)` | 直接 `execvp`，不经 shell，返回子进程退出状态 |
| `clock_ns()` / `exit(i64)` | 单调时钟和进程退出 |

平台原语由 C 运行时实现。`std.collections` 用 Aster 实现开放寻址、装载因子控制和重哈希；`std.text` 用 Aster 管理字符串构建片段；`std.io` 提供模块化 I/O 包装。

数组越界、字符串越界、无效切片、空数组 `pop`、除零退出状态为 70。静态语义错误退出 1，CLI 用法错误退出 2；缺失文件退出 66，无法写文件退出 73。程序的 `main` 返回值通过 POSIX 进程退出状态传出。
